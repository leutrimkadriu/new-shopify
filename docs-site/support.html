01

Prepare

Before contacting support

  1. 1

    Check the documentation

    Review the relevant guide and troubleshooting steps.

  2. 2

    Test a duplicate

    Duplicate the theme and determine whether the issue remains without recent custom code or app changes.

  3. 3

    Capture the details

    Note what you expected, what happened, and the shortest reliable steps to reproduce it.

02

Request details

What to include

Store and version

Your public store URL or myshopify.com URL and the theme version shown in Theme settings: VEYLUNE 2.0.5.

Issue description

A concise explanation of the affected page, expected result, actual result, and whether it happens consistently.

Steps to reproduce

Numbered steps beginning from a page URL, including the product, variant, menu, template, or section involved.

Environment

Browser, browser version, device, operating system, and whether the issue happens in a private browsing window.

Visual evidence

Screenshots or a short screen recording are useful when they avoid customer information and other sensitive data.

Recent changes

Tell us about newly installed apps, app embeds, Custom Liquid, template edits, or settings changed before the issue began.

Keep credentials private

Never send passwords, payment information, customer passwords, API secrets, private access tokens, or exported customer data. If access is genuinely required, use Shopify’s supported collaborator or staff access mechanisms and grant only the permissions needed.

Included

What theme support covers

  • Confirmed bugs in unmodified VEYLUNE theme code
  • Guidance using documented theme settings and sections
  • Clarification of built-in theme behavior
  • Reasonable help reproducing an issue in the current theme version

Outside standard scope

What theme support does not cover

  • Custom design or feature development
  • Third-party app code, setup, or conflicts
  • Shopify admin, billing, checkout, payments, or account issues
  • Custom code added by merchants or contractors
  • Content entry, catalog management, or store operations
03

Response expectations

What happens next

Support requests receive an initial response within two business days. Complex issues may require follow-up questions or a reproducible example.
