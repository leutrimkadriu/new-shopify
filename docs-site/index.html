01

Start here

Getting started

Install VEYLUNE as an unpublished theme, review it with your store data, then publish only when you are ready.

  1. 1

    Install the theme

    In Shopify admin, go to Online Store → Themes. Choose Add theme → Upload zip file, select the VEYLUNE package, and wait for it to appear in your theme library.

  2. 2

    Open the Theme Editor

    Find VEYLUNE in the theme library and choose Customize. Use the page selector at the top to move between home, product, collection, cart, blog, and other templates.

  3. 3

    Add your store content

    Choose menus, collections, products, imagery, policies, social links, and Markets settings. Preview desktop and mobile layouts before publishing.

  4. 4

    Publish when ready

    From the theme library, open the VEYLUNE actions menu and choose Publish. Publishing replaces the current live theme but keeps the previous one in the library.

Duplicate before customizing

Use the theme actions menu and choose Duplicate before major visual changes, app installations, or custom code. Name the copy with a date so you have a clear rollback point.

02

Foundation

Theme settings

Open the gear icon in the Theme Editor to edit global settings. These values apply across templates unless an individual section provides its own option.

Logo

Upload a standard logo and favicon, set the logo width from 60–260px, and refine the header logo height from 24–64px.

Colors

Set background, text, secondary text, accent, accent text, and border colors. Border strength controls the opacity of border treatments.

Typography

Choose Shopify-hosted heading and body fonts and adjust the global heading scale from 80–140%.

Layout

Control page width, section spacing, media radius, card radius, and button radius. Page width ranges from 1000–1800px.

Product cards

Choose Minimal, Editorial, or Commerce styling. Toggle vendor names, second-image hover, quick add, and color swatches.

Product pages

Enable sticky add to cart and set the low-stock threshold used by inventory messaging.

Collection pages

The Collection products section controls 2–5 desktop columns, grid spacing, card style, image visibility, products per page, sorting, and storefront filters.

Cart

Enable the AJAX cart drawer, cart notes, and free-shipping progress. The shipping threshold is entered in shop-currency subunits—for example, 5000 represents 50.00 in a two-decimal currency.

Search & motion

Predictive search can be enabled globally and supports keyboard navigation. Reveal animations can be toggled and are reduced for visitors who request reduced motion.

Social media

Add Instagram, TikTok, Pinterest, and YouTube URLs. Icons appear in the footer only when both the footer toggle and at least one URL are set.

03

Navigation

Header & navigation

Open the Header section in the Theme Editor. Choose Logo left/navigation center, Logo centered, or Compact editorial layout; select a Shopify navigation menu; and optionally enable sticky behavior, a transparent home page state, the Shopify customer account component, and localization in the mobile menu.

Configure navigation

  1. Create or edit a menu under Content → Menus in Shopify admin.
  2. Nest links under a top-level item to create a desktop dropdown/mega panel and expandable mobile group.
  3. Select that menu in the Header section.

Mega menu promotions

Add up to three Mega menu promotion blocks to the Header. Each block accepts an image, heading, and link. Promotion blocks appear inside nested desktop menu panels; if a link is empty, the promotion leads to the all-products collection.

Menu not visible?

A navigation item with no assigned links renders nothing. Confirm the selected menu contains published links and that nested links are indented beneath the intended parent.

Announcement bar

The header group includes one announcement bar with up to five messages. Messages can rotate every 3–12 seconds, link to a destination, and be dismissible for the browser session.

04

Closing navigation

Footer

The Footer supports up to four menu blocks plus text blocks. Select a Shopify menu for each menu block and use text blocks for concise brand or service information.

  • Newsletter: Enable the built-in Shopify customer newsletter form and edit its heading.
  • Social links: Enable the footer toggle and add social URLs under Theme settings → Social media.
  • Payment icons: Icons reflect payment methods enabled for the store; the theme does not create payment methods.
  • Localization: Country/currency and language selectors appear only when the store has multiple corresponding options available.
  • Policies: Published Shopify store policies are listed automatically with the copyright and Shopify attribution.
05

Editorial system

Home page sections

Use Add section in the home page template to assemble your storefront. VEYLUNE includes the following merchant-addable sections:

Slideshow

Up to eight editorial slides with responsive desktop/mobile images, optional automatic rotation, accessible controls, and reduced-motion support.

Editorial hero

Desktop/mobile imagery or hosted video, overlay, positioning, responsive height, text, and two calls to action.

Editorial product story

Image or video storytelling with up to four positioned product hotspots.

Kinetic collection rail

Horizontally browsable products with adjustable card width, count, card style, and optional progress indicator.

Split commerce story

Image/video, editorial copy, featured product, reversible layout, call to action, and color scheme.

Product lookbook mosaic

A 12-block mosaic mixing images, products, collections, and editorial text in standard, wide, or tall tiles.

Shop the story

Connect a supporting image and narrative to as many as six selected products.

Featured collection

Show 2–12 products with adjustable columns, spacing, card style, heading, and collection link.

Featured product

Feature a complete product experience with media, native swatches, variants, quantity, pickup availability, accelerated checkout, gift-card recipient fields, app blocks, and Custom Liquid.

Product recommendations

Show Shopify-generated related products with adjustable count and columns.

Collection list

Build a 2–4 column grid from selected collection blocks.

Product comparison

Compare up to four selected products using three merchant-written feature lines.

Before and after

A side-by-side comparison using before/after images and editable labels.

Image banner

Full-width image, overlay, copy, button, and adjustable height.

Image with text

Split image/copy composition with reversible image placement.

Columns

Two to four columns with image, heading, rich text, and optional link per block.

Rich text

Centered editorial copy with button style and color-scheme controls.

Scrolling text

Adjustable-speed marquee with default, dark, or accent color scheme.

Video

Shopify-hosted video or YouTube/Vimeo URL with optional muted autoplay.

Blog posts

Display 2–6 articles from a selected blog.

FAQ & collapsible content

Reusable question/answer or disclosure rows for structured supporting information.

Testimonials

Quote blocks with customer name, context, and color scheme.

Logo list

Linked logo blocks in a 2–6 column layout.

Newsletter & contact form

Native Shopify customer signup and contact forms with editable introductory copy.

06

Commerce

Product pages

Open the default product template in the Theme Editor and select Product information. Choose a Stacked or Editorial grid gallery, then arrange its blocks.

Product information blocks

  • Vendor, title, price, SKU, and inventory status
  • Variant picker: buttons, dropdowns, or swatches
  • Quantity selector and buy buttons
  • Optional dynamic checkout button
  • Description and reusable accordions
  • Page-backed popup, such as a size guide
  • Rating app mount point
  • Icon with text, complementary products, and Custom Liquid
  • Shopify app blocks

Product media

  • Images with responsive sizing
  • Shopify-hosted video
  • YouTube and Vimeo product media
  • Shopify 3D model viewer and supported-device AR
  • Thumbnail navigation when multiple media items exist
  • Variant media brought into view after selection

Variant selection updates the hidden variant ID, price, compare-at price, unit price, Shop Pay payment terms, SKU, availability, inventory, sticky-cart label, pickup availability, and featured media. Inventory messaging uses the global low-stock threshold when Shopify inventory tracking is active.

Gift cards and pickup availability

Gift-card products show optional recipient email, name, message, and scheduled-send fields inside the Add to cart form. Accelerated checkout is intentionally hidden for gift-card recipient purchases because Shopify validates recipient data through Add to cart. The issued gift-card page includes the code, QR code, recipient details, message, send date, expiration, and Apple Wallet when available.

Add a Pickup availability block to show location-specific pickup information. Shopify supplies the locations and pickup times; changing a variant refreshes the block. Without JavaScript, the selected variant’s pickup details remain available in an expandable disclosure.

Ratings require an app.

VEYLUNE provides standard review-badge mount points but does not create rating data. Install and configure a compatible reviews app if you want ratings to display.

07

Product discovery

Product cards

Global product-card settings apply to collection, search, recommendation, and featured-product grids unless a section offers its own card-style selection.

  • Styles: Minimal, Editorial, and Commerce.
  • Quick add: Products with one default variant add directly; products requiring a choice link to their product page.
  • Second image: Displays the second product media image on hover when available.
  • Swatches: Uses Shopify’s native image or color swatch data and falls back to a clearly labeled value when native swatch data is unavailable.
  • Vendor and badges: Vendor is optional. Sale, sold-out, and optional custom.badge product metafield output are supported.
08

Catalog

Collections

The collection template supports a collection image and description, 8–48 products per page, 2–5 columns, adjustable grid spacing, card style, filtering, sorting, active-filter removal, and pagination.

Desktop filter and sort changes update the product grid without a full page reload. A filter drawer provides the compact/mobile experience. List, boolean, and price-range filters are rendered when Shopify supplies them.

Enable storefront filters in Shopify.

If no filters appear, configure filters in Shopify’s Search & Discovery app and confirm that products have the relevant option or metafield data.

09

Checkout path

Cart

When the global cart-drawer setting is enabled, product forms add with AJAX, refresh the header count, render the updated drawer, and announce status messages to assistive technology. The drawer and standalone cart page support quantity changes and item removal.

  • Optional order notes in both cart experiences
  • Subtotal and currency-aware money output
  • Optional free-shipping progress in the drawer
  • Checkout submission and Shopify accelerated checkout buttons on the cart page
  • Shop Pay payment terms when the store and cart qualify
  • Standalone cart fallback when the drawer is disabled

Set the free-shipping threshold in currency subunits and keep it aligned with the actual shipping rate configured in Shopify admin. The theme displays progress; it does not create or enforce the shipping rate.

10

Findability

Search

The header opens a search drawer. When predictive search is enabled, entering two or more characters requests up to six matching products, collections, pages, and articles. Results support arrow-key navigation; disabling the setting preserves the standard search form.

The full search template handles products and other Shopify result types, supports 8–40 results per page, adjustable columns, storefront filters, sorting, active-filter removal, and pagination.

11

Markets

Localization

VEYLUNE can show country/currency and language selectors in the footer and mobile menu. A selector appears only when Shopify reports more than one available country or language.

Configure markets, domains, currencies, and published languages in Shopify admin first. The theme submits selections through Shopify’s native localization form.

12

Composition

Sections & blocks

Sections are the main editable page regions in Shopify’s Theme Editor. Add, remove, hide, and reorder supported sections from a JSON template. Blocks are repeatable items within a section—for example FAQ questions, testimonial quotes, footer menus, product hotspots, or product-information rows.

Header and footer use Shopify section groups, so their sections and blocks can be managed consistently across the storefront. Template-specific main sections—product, collection, cart, search, article, and blog—provide settings tailored to their resource type.

13

Integrations

Apps

Shopify app blocks are supported inside the main Product information section and Featured product section. After installing a compatible theme app extension, open the relevant section, choose Add block, and select the app block.

VEYLUNE also exposes review-badge mount points on product cards and product pages. Display depends on the installed app’s compatibility and configuration.

Test app changes on a duplicate.

Apps can inject scripts, blocks, or app embeds. Confirm product selection, cart, mobile layout, and performance before applying the same configuration to the published theme.

14

Advanced

Custom Liquid

VEYLUNE includes a standalone Custom Liquid section plus Custom Liquid blocks in Product information and Featured product. Use these for small Shopify Liquid or HTML additions that do not require editing theme source files.

{% assign message = 'Made with care' %}
<p>{{ message }}</p>
Custom code is your responsibility.

Test Custom Liquid on a duplicate theme first. Invalid markup, expensive Liquid loops, or third-party scripts can affect layout, accessibility, security, and performance.

15

Responsive design

Mobile behavior

VEYLUNE switches desktop navigation to a drawer on smaller screens, presents filters in a drawer, adapts product grids, and supports a dedicated mobile hero image and height. Drawers trap keyboard focus, close with Escape, and restore focus to their trigger.

Preview both desktop and mobile in the Theme Editor. Test long menu titles, product names, variant labels, translations, and real imagery on a physical phone before publishing.

16

Inclusive storefronts

Accessibility

Confirmed implementation includes a skip link, semantic navigation landmarks, visible labels or visually hidden labels for controls, live-region cart messaging, keyboard-operable drawers and modals, Escape handling, focus trapping/restoration, current-page states, and reduced-motion handling.

Merchants remain responsible for meaningful image alt text, readable color choices, descriptive links, video captions, heading order, app accessibility, and ongoing testing.

No legal compliance claim

These features support accessible use, but they do not by themselves establish WCAG, ADA, or other legal compliance. Accessibility should be tested with your final content, apps, and configuration.

17

Fast by practice

Performance

  • Upload images close to their displayed aspect ratio and avoid unnecessarily large originals.
  • Use video selectively, compress it before upload, and avoid several autoplay videos on one page.
  • Remove app embeds and scripts you no longer use.
  • Keep the home page section count intentional; every product rail, video, and app adds work.
  • Retest product, collection, and home page performance after adding apps or campaign media.

VEYLUNE uses responsive Shopify images, lazy loading for non-priority media, deferred JavaScript, and on-demand recommendations. No specific Lighthouse score is promised because store content and apps materially affect results.

Resolve common issues

Troubleshooting

Product does not add to cart

Confirm the selected variant is available and the quantity is valid. Test in a clean browser window, then temporarily disable recently added app embeds on a duplicate theme. If only one product fails, inspect its variants and sales-channel availability in Shopify admin.

Cart count does not update

Refresh the page and test another product. Confirm the cart drawer is enabled if you expect AJAX behavior. Browser extensions or an app that replaces product forms/cart markup can interrupt updates; test the duplicate theme without recent app changes.

A variant shows as unavailable

Check that the exact option combination exists, has inventory or overselling enabled, is available to the Online Store sales channel, and is published to the visitor’s market.

Product or section images do not appear

Assign media in the relevant product or section setting. Confirm the image is not still processing, preview the correct template, and replace the file if Shopify reports an upload error.

The menu does not appear

Open the Header section and select a menu that contains published links. For dropdowns, verify child links are nested beneath a top-level item in Content → Menus.

Collection filters do not appear

Configure filters in Shopify Search & Discovery. Filters also need relevant product option, vendor, price, availability, or metafield data before Shopify returns them to the theme.

Predictive search does not work

Enter at least two characters, confirm relevant storefront resources are published, and test without browser extensions. The full search page remains available through the submitted search form.

Social icons do not appear

Add complete social URLs under Theme settings → Social media and enable Show social links in the Footer. Empty platforms are intentionally omitted.

Payment icons do not appear

Enable Show payment icons in the Footer and confirm payment methods are enabled in Shopify admin. VEYLUNE only displays methods returned by Shopify.

Theme changes are not visible

Confirm you edited the template and theme you are previewing, save the Theme Editor, and refresh the preview. Check whether a section is hidden and whether you are viewing the published theme instead of an unpublished duplicate.

An app block does not appear

Confirm the app provides a theme app extension and supports the chosen template. Add it inside Product information or Featured product, enable any required app embed, and follow the app developer’s setup instructions.
