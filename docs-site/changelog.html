A concise record of merchant-facing theme releases.

2.0.5Public theme rename

Version 2.0.5

  • Renamed the public theme branding to VEYLUNE.
2.0.4Performance hardening

Version 2.0.4

  • Reduced initial JavaScript work through conditional and interaction-based component loading.
  • Hardened dynamic Theme Editor section loading, predictive search accessibility, and reduced-motion behavior.
2.0.3Final requirement delta

Version 2.0.3

  • Added every required font-picker variant and moved external video rendering to Shopify's native Liquid filter.
  • Completed the final current Theme Store requirement delta audit.
2.0.2Theme Store compliance refinement

Version 2.0.2

  • Added cart accelerated checkout, selling-plan details, unit pricing, variant options, cart-level discounts, search filters, and Follow on Shop.
  • Added focal-point-aware imagery, collection featured images, scheduled gift card details, gift card QR support, and final terminology and validation audits.
2.0.1Shopify integration refinement

Version 2.0.1

  • Added native pickup availability and gift card recipient delivery fields.
  • Added image-first swatches, combined listing navigation, standard review metafields, and final compatibility audits.
2.0.0Premium editorial redesign

Version 2.0.0

  • New editorial navigation, product storytelling, product information architecture, design tokens, responsive behavior, and accessibility refinements.
  • Added Shopify's customer account component and removed generic urgency countdowns.
