# Setup

1. Connect Shopify CLI to a development store and run `shopify theme dev` from the project root.
2. Add products, collections, menus named `main-menu` and `footer`, policies, and blog posts.
3. Choose a global style under Theme settings, then assign products and media to homepage sections.
4. Set an optional `custom.badge` single-line product metafield for merchant-authored card badges.
5. Configure a free-shipping threshold only when the store's shipping rules support the claim.
6. Create pages for size guides, shipping, returns, FAQ, and brand story, then connect them to product blocks and templates.

Do not include `config/markets.json`. For a submission zip, package only Shopify-supported theme directories.
