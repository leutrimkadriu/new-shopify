# VEYLUNE features

- Three global product-card modes: minimal, editorial, and commerce.
- Editorial hero, product story hotspots, kinetic product rail, split commerce story, lookbook mosaic, and sticky shop-the-story composition.
- Product media for images, hosted and external video, and 3D models.
- Button/dropdown variant selectors, dynamic price/media state, dynamic checkout, accessible size-guide modal, inventory messaging, app blocks, and sticky add to cart.
- Storefront filters, sorting, pagination, predictive search, Ajax cart drawer, shipping threshold display, cart notes, and a standalone cart fallback.
- Section-group header and footer, localization, market-safe money output, newsletter, journal, FAQ, contact, password, 404, and gift card experiences.
- Native lazy loading, one reveal observer, reduced-motion handling, focus traps, live regions, and no external runtime dependencies.
