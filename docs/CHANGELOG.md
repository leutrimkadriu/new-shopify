# Changelog

## 2.0.5 — 2026-08-29

- Renamed the public theme branding to VEYLUNE.

## 2.0.4 — 2026-08-28

- Reduced initial JavaScript work through conditional and interaction-based component loading.
- Preserved dynamically inserted Theme Editor sections by loading their required component scripts on section lifecycle events.
- Improved predictive search relationships and reduced-motion behavior during AJAX filtering.

## 2.0.3 — 2026-08-27

- Added bold, italic, and bold-italic font variants for every font-picker font.
- Replaced hard-coded YouTube and Vimeo iframe URLs with Shopify's native external video filter.
- Completed the final current-requirements delta audit.

## 2.0.2 — 2026-08-27

- Added cart accelerated checkout buttons, selling-plan details, unit pricing, variant options, and cart-level discounts.
- Added search filters and sorting, Follow on Shop, focal-point-aware imagery, and collection featured images.
- Added scheduled gift card delivery details and a scannable gift card QR code.
- Completed Shopify terminology, metadata, schema, Liquid, and development-artifact audits.

## 2.0.1 — 2026-08-27

- Added variant-aware local pickup availability using Shopify's native store availability endpoint.
- Added native gift card recipient fields with scheduled delivery support.
- Added image-first product option swatches, combined listing navigation, and unavailable states.
- Replaced the legacy review badge mount with Shopify standard review metafields.
- Completed translation, schema, responsive, and development-artifact audits.

## 2.0.0 — 2026-08-27

- Rebuilt the navigation, product experience, design system, presets, accessibility behavior, and mobile progressive enhancement.
- Added Shopify's required customer account component.
- Removed generic countdown urgency features.

## 1.0.0 — 2026-08-22

- Initial VEYLUNE editorial commerce release.
- Added global navigation, localization, product discovery, storefront filtering, predictive search, Ajax cart, structured data, and accessible interaction primitives.
- Added the complete editorial and standard section library with demo-ready JSON templates.
